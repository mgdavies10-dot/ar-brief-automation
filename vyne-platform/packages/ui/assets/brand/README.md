# VYNE brand assets (canonical)

## `vyne-logo-primary.png`

The founder-approved VYNE Strategies primary logo (supplied and approved
2026-07-20; resolves open question Q-9 for the v1 slice). Symbol ("V/=") over
the VYNE wordmark; midnight navy on white; 1536×1024, 24-bit RGB (no alpha —
the white ground is part of the asset).

**Usage rules (founder direction, 2026-07-20):**
- Use this exact file. Never redraw, reinterpret, trace, simplify, or recreate
  the symbol; never stretch, crop, distort, or apply visual effects.
- Preserve original proportions (3:2 canvas); the canvas margin is part of the
  mark's clear space — give it room beyond that.
- Because the asset has no transparency, place it only on white (or let its
  white ground read as an intentional plate).
- Import in apps via `@vyne/ui/assets/brand/vyne-logo-primary.png`.

**Still open (per Architecture §18 note on Q-9):** a vector (SVG/AI) master and
reversed/on-navy variants — raster-only is acceptable for the v1 slice, not for
print deliverables. Request from the founder when needed.
