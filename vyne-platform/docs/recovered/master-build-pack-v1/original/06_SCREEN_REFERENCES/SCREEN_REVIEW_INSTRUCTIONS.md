# Screen Review Instructions

Treat these screenshots as current-state references unless the founder labels them otherwise.

For each screen, Claude should produce:
- purpose and user role;
- elements worth preserving;
- usability or hierarchy issues;
- security or visibility risks;
- relationship to the canonical workflow;
- proposed target-state screen;
- open founder decisions.

Do not infer that current visual treatment or navigation is approved merely because it exists.
