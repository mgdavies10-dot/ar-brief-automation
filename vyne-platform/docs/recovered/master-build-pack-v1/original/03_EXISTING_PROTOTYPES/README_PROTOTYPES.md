# Existing Prototype Rules

These files may contain useful workflows, screens, calculations, or code. They are not automatically production-ready.

Claude must:
- inspect before reusing;
- identify reusable logic separately from reusable design;
- document security weaknesses;
- avoid carrying forward localStorage-only confidential persistence, hard-coded passcodes, client-side-only permissions, or monolithic single-file architecture;
- preserve formulas only after comparison with canonical model standards and hand-check tests;
- create a migration map rather than silently replacing or discarding data.
