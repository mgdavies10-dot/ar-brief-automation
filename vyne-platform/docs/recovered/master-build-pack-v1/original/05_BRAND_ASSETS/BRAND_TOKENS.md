# VYNE Brand Tokens

## Core palette
- Primary navy: `#12233F`
- Forest green: `#214E3B`
- Gold: `#B48A35`
- Warm ivory: `#F7F4ED`
- Slate: `#425066`
- White: `#FFFFFF`

## Character
Institutional, independent, discreet, modern, warm, sophisticated, confident, calm, and premium without being flashy.

## Logo
Use the supplied primary logo as the current authority. Do not redraw, distort, recolor casually, or recreate it with text. Request a vector/SVG asset before final production launch if one has not been supplied.

## Design direction
- generous whitespace
- strong editorial hierarchy
- restrained borders and shadows
- precise tables and scorecards
- executive-report quality
- calm motion used sparingly
- consistent print and screen experience

## Avoid
- neon colors
- generic SaaS gradients
- excessive pill shapes
- playful startup illustration
- dense dashboard clutter
- job-board visual language
- unlicensed stock imagery
