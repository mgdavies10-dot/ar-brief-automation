### The finding that matters most

**Winthrop is advisor-paid.** Its homepage states *"owner-operated, fully confidential, no platform
allegiance, **advisor-paid model**"* and *"We represent the advisor."*

That is a genuinely different economic model from VYNE's, and it is the **strongest available counter to
VYNE's disclosure posture**. Diamond claims *"unbiased"* while being firm-paid — a claim VYNE has ruled it
will never make. Winthrop instead **removes the conflict** and says so.

**VYNE cannot out-claim Winthrop on independence.** What VYNE can do is out-perform it on **method,
evidence discipline, and confidentiality** — and be plainer than Diamond about economics. The site must
argue on that ground, not on neutrality.

### Bridgemark's calculators — the specific benchmark

| Calculator | Inputs | Outputs |
|---|---|---|
| Independent Advisor Net Payout | gross revenue · BD deductions · practice overhead | net take-home |
| W2 Advisor Net Payout | payout grid · deferred comp · expenses (sliders) | net take-home |
| Practice Value | "a few inputs" | EBITDA + enterprise value |
| W2 Sunset Program | sliders, unspecified | program valuation |

Their public hedge: *"industry-typical assumptions… directional estimates… a starting point for better
questions, not a substitute for a certified valuation or negotiated offer."* **No email gate.**

> ⚠ **VYNE's own founder ruling prohibits "take-home pay" unless taxes are actually modelled.** Bridgemark
> uses it. VYNE will use *estimated pre-tax owner economics* / *estimated pre-tax cash compensation*.
> **Their hedge language is close to VYNE's drafted boundary — which is a reason to write ours
> independently, not to borrow theirs.**

## 5 · Lead-generation architecture

**Progressive trust — the approved model:**

```
1 anonymous research   → no capture. Full content access.
2 newsletter           → email only. One field.
3 tool user            → Eight Questions or calculator. Anonymous result shown FIRST.
                          Email optional, for the deeper report only.
4 verified advisor     → self-declared channel + practice scale in BANDS
5 confidential convo   → name, email, phone optional, context
6 active engagement    → hand off to the operating artifacts (Orientation → Entry Review)
```

**Never requested at the top of the funnel:** CRD · exact T12 · exact AUM · documents · client
information · anything sensitive.

**Absolute rule, restated on every form:** **no information submitted through this website triggers firm
contact or submission of any kind.** Firm contact requires separate, written, firm-specific
authorization.

**CRM handoff fields:** source · page · topic · tool used · consent state + timestamp + version ·
requested next action · disclosure version shown.

**Consent:** explicit, unbundled, versioned, timestamped, revocable, logged. **Nothing pre-ticked.**

## 6 · Calculator architecture

Four tools, one shared engine. **Not a deferred side project.**

| Tool | Output framing |
|---|---|
| Independent Advisor Net Payout | **estimated pre-tax owner economics** |
| W2 Advisor Net Payout | **estimated pre-tax cash compensation** + deferred shown separately, never as cash |
| Practice Value Scenario Explorer | a **range**, from normalized EBITDA × multiple **and** recurring revenue × multiple |
| W2 Sunset Program Scenario Explorer | advisor-entered terms only; **no published "wirehouse sunset percentage"** |

**Every tool carries:** transparent formula shown · visible, editable assumptions · sensitivity range ·
methodology + effective date + reviewer · "What this cannot tell you" · consultation handoff.

**Every tool refuses:** strategic recommendation · formal valuation · firm ranking · portability
conclusion · best-fit conclusion · **the phrase "take-home pay"** unless taxes are actually modelled ·
hidden industry defaults — *if no defensible default can be sourced, the field stays blank or requires
entry.*

**Build order:** formula-specification record **and** interface together, per field —
name · definition · required/optional · default · **source** · **effective date** · formula · calculation
order · tax treatment · rounding · output · sensitivity · override · validation · edge cases ·
disclaimer · **professional reviewer** · **refresh cadence**.

**Gate:** documented calculation QA with test cases before publication, and **counsel review of
disclaimers, valuation positioning, data collection and IP/trade dress.** Interfaces may be built now;
**publication is gated.**

**IP:** built independently from the underlying mathematics. **No Bridgemark code, layout, wording, help
text, charts, disclaimers or visual expression.**
