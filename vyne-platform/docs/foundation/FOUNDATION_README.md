# VYNE Foundation — read this first

These are VYNE's foundational documents. Read them **in this order:**

1. **The VYNE Constitution** — [`THE_VYNE_CONSTITUTION.md`](THE_VYNE_CONSTITUTION.md) *(ratified 2026-07-23, v1.0)*
2. **Founder Alignment Memo** — `FOUNDER_ALIGNMENT_MEMO.md` *(forthcoming)*
3. **The VYNE Story** — `THE_VYNE_STORY.md` *(forthcoming)*

What each is for:

- The **Constitution** defines VYNE's **enduring principles** — they change rarely,
  and only by deliberate, explained amendment.
- The **Founder Alignment Memo** explains how those principles are **interpreted
  today** — the current strategy, boundaries, and language rules. It evolves as
  strategy does, but never contradicts the Constitution.
- The **VYNE Story** communicates those principles **externally, through
  narrative** — the company's story, in a human voice.

**Precedence.** If these documents ever appear to conflict, the order of authority
is:

> **The VYNE Constitution → Founder Alignment Memo → The VYNE Story**

Every downstream artifact — the roadmap, product specs, the website, brand
standards, hiring — derives from these three and must remain consistent with them.
The history of *philosophical* changes (not product changes) lives in
[`FOUNDATION_CHANGE_LOG.md`](FOUNDATION_CHANGE_LOG.md).
